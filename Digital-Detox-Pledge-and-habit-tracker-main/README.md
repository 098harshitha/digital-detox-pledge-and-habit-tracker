# Digital-Detox-Pledge-and-habit-tracker
A simple web application that helps users track their offline hours, monitor digital detox progress, and celebrate milestones with badges.

# Features
Set a digital detox pledge.

Log offline hours.

Track progress toward detox goals.

View milestones and earn badges.

Get interactive feedback using the Web Audio API.

Responsive and simple user interface.

# Tech Stack
HTML

CSS

JavaScript

Web Audio API

Python (for the lightweight server)

# Project Goal
To help users build healthier digital habits by tracking offline time, monitoring progress, and celebrating achievements.
